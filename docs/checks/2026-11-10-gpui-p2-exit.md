## How

Both apps were driven from outside, the same way, by [uiprobe.cs](2026-11-10-gpui-p2-exit/uiprobe.cs), a small Win32 and UI Automation tool built with the .NET Framework's `csc.exe`. It reads window rectangles, minimised and maximised states, the foreground window, UI Automation names, screen pixels and the cursor shape. It answers to WM_NULL so the UI thread's stalls can be timed. Each app got a fresh data folder with a written `settings.json` (`window`, `appearance.theme`, `lastProject`, `recentProjects`); a close was a plain `taskkill` (WM_CLOSE), so the app saved its bounds. Screenshots are the screen's pixels in the window's rectangle, both apps at the same saved size on the main screen. The project's path, in a temporary folder of the machine's user, is painted over in the status bar, the console and the home screen's recent list.

### 10,000 and 2,000 tests (VL-26 to VL-29)

[vl.mjs](2026-11-10-gpui-p2-exit/vl.mjs) drives both apps the same way, on the bench's generated projects (`writeBigProject`, 5 and 25 features per module), window 1400 x 900 on the second screen, 3 rounds each, medians below. Each round:

1. Opens the project on a fresh data folder and times the tree's top folder to its UI Automation name.
2. Closes and opens the top folder, selects a test and presses Down, each timed from the input to the first changed pixel in the tree. A screen capture polled at about 2 ms, so this includes the compositor's frame.
3. Runs all with the bench's sampler on, for peak memory and CPU of the app and of Java. It scrolls the tree 60 notches during the run.
4. Times "Finished", from Karate's last top-level `SCENARIO_EXIT` to the name "Finished" showing in UI Automation (polled at 25 ms).

For GPUI Grace, a second tool sends WM_NULL every 5 ms and times the answer: the longest stall of its UI thread, while opening, during the run and during the scroll. That wakes GPUI Grace 200 times a second, so its CPU and memory come from 3 more rounds without it ("no ping"); the timings agree between the two sets. Electron Grace's UI thread is in its renderer, which WM_NULL does not reach: its frames are the bench's `smooth.*` rows above.

The raw rounds are in [runs/](2026-11-10-gpui-p2-exit/runs/).

| Measure | GPUI 10k | Electron 10k | GPUI 2k | Electron 2k |
|---|---|---|---|---|
| Open, spawn to the tree (ms) | 4,425 | 4,821 | 1,757 | 1,814 |
| Memory after open (MB, app) | 57 | 278 | 44 | 177 |
| Longest UI stall while opening (ms) | 17 | (bench) | 18 | (bench) |
| Close / open the top folder (ms) | 35 / 35 | 24 / 41 | 35 / 27 | 23 / 41 |
| Select a test / Down (ms) | 34 / 50 | 41 / 25 | 26 / 35 | 41 / 24 |
| Run all: longest UI stall (ms) | 27 | (bench: `smooth.run.frame@10k` 117) | 19 | (bench: 42) |
| Run all: longest stall while scrolling (ms) | 17 | (bench: `smooth.scroll.run.frame@10k` 83) | 19 | (bench: 42) |
| Run all: peak memory app / Java (MB) | 267 / 247 | 698 / 252 | 91 / 238 | 282 / 189 |

Screenshots, each app at the same saved size, in light and dark: [home](2026-11-10-gpui-p2-exit/home-light-gpui.png) ([Electron](2026-11-10-gpui-p2-exit/home-light-electron.png)), [home dark](2026-11-10-gpui-p2-exit/home-dark-gpui.png) ([Electron](2026-11-10-gpui-p2-exit/home-dark-electron.png)), [project](2026-11-10-gpui-p2-exit/project-light-gpui.png) ([Electron](2026-11-10-gpui-p2-exit/project-light-electron.png)), [project dark](2026-11-10-gpui-p2-exit/project-dark-gpui.png) ([Electron](2026-11-10-gpui-p2-exit/project-dark-electron.png)).

Same in both: the colours (ground, sheet, console, the primary green of Open folder… and Run all, Run all as the only primary button with its play icon in on-primary ink), the layout of home and of the project view, the toolbar order, the tag chips, the tree's icons and status rings, the empty details, the console's banner.

Different:

- **Text is smaller in GPUI Grace.** At the same window size, the toolbar's button labels, the project name, the home screen's heading and folder names, and the console's monospace text are each one to two pixels smaller than in Electron Grace, and the labels look lighter. This shows in every view.
- **No Grace icon in the title bar.** GPUI Grace shows a plain window icon where Electron Grace shows the Grace logo.
- **The bottom panel is taller.** Its default height differs, so GPUI Grace's tree and details are shorter.
- **Smaller home rows.** Rows are about 55 px high against 66 px, with a smaller ✕.
- **Not in GPUI Grace yet, as its phases plan:**
  - the status bar's version (`Grace 1.0.0-rc.9`);
  - the toolbar's watch toggle and the rows' debug buttons (P4);
  - the HTTP tab's count (P3).
