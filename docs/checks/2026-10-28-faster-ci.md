- Wall time met both targets within about 40 s. The ready run's long pole is `e2e (1)`: Playwright gave it 64 tests and the slower specs (`history`, `env`), 98 s more than `e2e (2)`.
- Billed minutes are one above each estimate. On a draft run the two `e2e` jobs took 62 s each, so each bills 2 minutes instead of 1.
- `runner.history.test.ts` took 111 s in the draft run and 154 s in the ready run (162 s on PR #31), on the same code. That swing is larger than any rebalancing move, so the unit halves stay as they are: on the three measured runs both splits average about the same longest half (233 s and 234 s).
