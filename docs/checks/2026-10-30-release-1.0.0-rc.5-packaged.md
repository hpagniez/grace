# Packaged app check: release 1.0.0-rc.5

Date: 2026-10-30
Branch: `release/v1.0.0-rc.5` at 85887177 (`develop` after #122, plus the version bump)
Machine: Windows 11 Pro 10.0.26300 (x64), Node 24. No Java on the machine.
Features since 1.0.0-rc.4: the premium look and feel with the Appearance setting (#107), the updater fixes (#119, #120), and research notes (#114, #118). Bundled Temurin JRE 21.0.12.1+1 and Karate 2.1.4 are unchanged. This is the first release an installed 1.0.0-rc.4 can update to: switching versions is checked by hand once it is published.

Playwright cannot drive the packaged exe (ADR 0004), so this check covers what only packaging can break.

## By hand (done by a person)

Unzip `Grace-win32-x64-1.0.0-rc.5.zip` (from `npm run make` or the release workflow) into a folder of its own and start `Grace.exe`. Use writable copies of the fixtures in `test/fixtures/projects/`. Data from 1.0.0-rc.4 is read as it is; no migration (AGENTS.md).

Look and feel (#107):
1. The home screen shows the Grace logo and the new type (IBM Plex). The status bar reads `Grace 1.0.0-rc.5`. With a project open, the console banner reads `Grace 1.0.0-rc.5 · Karate 2.1.4 · Java 21.0.12.1+1`.
   - Result: passed (checked by Tusquito, 2026-10-30).
2. `⚙ Settings` › Appearance: `Follow Windows` is selected. Pick `Dark`: the whole window turns dark at once. Close Grace and start it again: it starts dark, with no white flash. Pick `Follow Windows` again.
   - Result: passed (checked by Tusquito, 2026-10-30).
3. Open the `clean` fixture and click Run all. The run reaches `Finished` with 8 passed and 1 failed, and Report opens the HTML report. Narrow the window until a tree label is cut: hovering it shows the full name in a tooltip, and a click closes it.
   - Result: passed (checked by Tusquito, 2026-10-30).
4. Close the app. Task Manager shows no `java.exe` left.
   - Result: passed (checked by Tusquito, 2026-10-30).
