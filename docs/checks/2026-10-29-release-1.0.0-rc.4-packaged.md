# Packaged app check: release 1.0.0-rc.4

Date: 2026-10-29
Branch: `release/v1.0.0-rc.4` at 9c67e625 (`develop` after #111, plus the version bump)
Machine: Windows 11 Pro 10.0.26300 (x64), Node 24. No Java on the machine.
Features since 1.0.0-rc.3: app updates (#77, #110), loading always visible (#99), and CI, docs and research changes. App updates is the first release with the updater (`FIRST_UPDATER = 1.0.0-rc.4`): this version cannot update from an earlier one, and switching to a newer version can only be tried for real once 1.0.0-rc.5 is published, because a packaged build ignores `GRACE_UPDATE_FEED`.

Playwright cannot drive the packaged exe (ADR 0004), so this check covers what only packaging can break.
