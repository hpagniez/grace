# Packaged app check: hotfix 1.0.0-rc.6

Date: 2026-10-30
Branch: `hotfix/v1.0.0-rc.6` at 21be6547 (`main` at 1.0.0-rc.5, plus the fix for #131 and the version bump)
Machine: Windows 11 Pro 10.0.26300 (x64), Node 24. No Java on the machine.
Fix: updating hung at `Unpacking…` in every packaged version up to 1.0.0-rc.5 (#131). Electron's asar-aware `fs` takes an `.asar` file for a folder, so the unpacked app failed its check and removing the staging folder never finished. The updater now goes through `original-fs`.

Playwright cannot drive the packaged exe (ADR 0004), and a build that is not packaged never installs (R13.1), so this check is the only one that runs an install for real.

## Install for real (run by an agent)

A packaged 1.0.0-rc.6 cannot update yet: no newer version is published. A rollback goes through the same steps as an update (R8: download, check, unpack, switch), so it stands in for one.

## By hand (done by a person)

Nothing more before merging. Once a version newer than 1.0.0-rc.6 is published, update an installed 1.0.0-rc.6 to it from the status bar's `Update`: Grace restarts as the new version with `Updated to <version>.`, and `<install>.old` and `<install>.update` are gone shortly after. People on 1.0.0-rc.4 or 1.0.0-rc.5 must install 1.0.0-rc.6 from its zip by hand.
