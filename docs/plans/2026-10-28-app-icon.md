# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Grace its own icon: the 1947 logbook moth cut in two by a green strike, on `Grace.exe`, the taskbar and the window.

**Architecture:** Two hand-written SVG sources in `assets/`. `npm run icon` renders them in the installed Microsoft Edge (Playwright, `channel: "msedge"`) and packs the PNGs into `assets/icon.ico` with a pure `ico()` writer. The `.ico` is committed, so builds and CI never render. Forge embeds it in the exe; `BrowserWindow` gets it only when not packaged, because the packaged window already takes the exe's icon.

**Tech Stack:** Electron Forge 7, `@playwright/test` 1.64.1 (already a dev dependency), Node 24, Vitest 5.

**Spec:** [ADR 0013](../decisions/0013-rename-the-app-to-grace.md), section Icon and mascot. The mascot is out of scope.

## Global Constraints

- Branch `feature/app-icon`. Conventional Commits, AGENTS.md rules. No new dependency.
- Colours: tile `#151821` (rounded square, `rx` 52 of 256), moth `#ece6d8`, wing spots `#c9bfa8`, strike `#3fcf6e`.
- Sizes in the `.ico`: 16, 24, 32, 48, 64, 128, 256, each a 32-bit PNG with transparent corners. 16, 24 and 32 come from `assets/icon-small.svg` (no antennae, no wing spots, thicker strike); 48 and up from `assets/icon.svg`.
- Avoid what ADR 0013 lists: nothing close to Karate Labs' logo, no Japanese text.

## Review Focus

1. **The 256 px entry**: ICO stores 256 as width byte `0`. Test: Task 1 `writes 256 as 0`.
2. **Offsets**: each entry's offset points at that PNG's first byte. Test: Task 1 `points each entry at its png`.
3. **16 px legibility**: the moth and strike still read in the taskbar. Check: Task 2 renders a preview at 256/64/32/16 for the maintainer.
4. **Packaged exe icon**: rcedit embedded it. Check: Task 3 extracts the icon from `out/Grace-win32-x64/Grace.exe`.

### Task 1: ICO writer

**Files:** Create `scripts/make-icon.mjs`, `scripts/make-icon.test.ts`.

**Interfaces:** Produces `ico(images: { size: number; png: Buffer }[]): Buffer` (ICONDIR `0, 1, n`; 16-byte entries `width, height, 0, 0, planes 1, bpp 32, bytes, offset`; PNGs after the directory, in order).

- [ ] **Step 1:** Tests: `writes the header and one entry per image`, `writes 256 as 0`, `points each entry at its png`. Run `npx vitest run scripts/make-icon.test.ts`. Expected: FAIL, no module.
- [ ] **Step 2:** Implement `ico`. Same command. Expected: PASS.

### Task 2: Draw and render

**Files:** Create `assets/icon.svg`, `assets/icon-small.svg`, `assets/icon.ico`. Modify `scripts/make-icon.mjs` (`main()`, run only when executed), `package.json` (`"icon": "node scripts/make-icon.mjs"`).

- [ ] **Step 1:** Draw the SVGs (viewBox `0 0 256 256`). `main()` renders each size at device scale 1 with `omitBackground`, writes `assets/icon.ico`.
- [ ] **Step 2:** `npm run icon`. Expected: `assets/icon.ico` with 7 entries. Render a 256/64/32/16 preview and send it.

### Task 3: Wire it

**Files:** Modify `forge.config.mts` (`packagerConfig.icon: "assets/icon"`), `src/main.ts` (`icon` when `!app.isPackaged`).

- [ ] **Step 1:** `npm run package`, extract the icon of `out/Grace-win32-x64/Grace.exe` with `System.Drawing.Icon.ExtractAssociatedIcon`. Expected: the moth, not Electron's atom.
- [ ] **Step 2:** `npm run lint && npm run typecheck && npm test`, then `npx playwright test e2e/startup.spec.ts`. Expected: all pass.
- [ ] **Step 3: Commit** `feat(ui): give grace its moth icon`.
