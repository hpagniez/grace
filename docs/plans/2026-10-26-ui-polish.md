# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the bottom panel resizable with a remembered height, start the window painted in the app's theme, theme the scrollbars, start Open… next to the last project, and make the cursor match each control and the busy state.

**Architecture:** The panel-height rules (limits, key steps, `localStorage` read and write) are pure functions in `src/renderer/panelHeight.ts`. A `Splitter` component at the top of `BottomPanel` uses them; the clamp itself is plain flexbox (`main` has a 120 px minimum, the panel shrinks down to 96 px). Cursors and scrollbars are a few base rules in `src/index.css`, plus classes on the app's root. Window start-up (`show: false`, background colour, minimum height, show fallback) and the Open… dialog's start folder live in `src/main.ts`. A static startup screen in `index.html` is removed once the app is drawn.

**Tech Stack:** Electron 45, Solid 2 RC, Tailwind v4, TypeScript, Vitest 5, Playwright 1.64.

**Spec:** [docs/specs/2026-10-26-ui-polish.md](../specs/2026-10-26-ui-polish.md) (R1–R5). Builds on the walking-skeleton, run-history and HTTP-inspector specs (bottom panel and its tabs).

## Review Focus

1. **`localStorage` that throws or holds junk** (blocked storage, `"1e999"`, `"NaN"`, a height taller than the screen): the panel falls back to 192 px or is clamped, and nothing throws. Tests are in Task 1 (`loadPanelHeight` cases, including a throwing `getItem`) and Task 2 (`a saved height taller than the window is clamped at start`).
2. **A drag released above the window's top edge**: the drag ends, the height saved is the maximum, and the app's root loses `row-resize`. Test: Task 2 `releasing a drag above the window keeps the maximum and ends the drag`.
3. **Keys at a limit, and keys the splitter doesn't use**: Down at 96 px, Up or End at the maximum, Tab, letters. The height stays the same, nothing is saved, and Tab still moves focus on. Tests: Task 1 `keyHeight` cases, and Task 2 `Tab moves focus past the splitter`.
4. **Dragging while busy**: during a drag the root shows `row-resize`. After the drop it goes back to `progress` while the run goes on. Test: Task 3 `the drag cursor wins over the busy cursor`.
5. **A renderer reload** (Forge dev reloads once after start): the startup screen comes back, then goes again, and the page never holds two app roots. Test: Task 6 `a reload shows the app once`.

**Interfaces:**
- Produces, with no imports from Electron or Node:
  - `PANEL_DEFAULT`, `PANEL_MIN`, `MAIN_MIN`, `PANEL_STEP` and `PANEL_KEY`, with the values in Global Constraints.
  - `maxPanel(room: number): number`: the largest panel height when `main` plus the panel have `room` px between them. That is `Math.max(PANEL_MIN, room - MAIN_MIN)`, so it is never below the minimum.
  - `clampPanel(h: number, max: number): number`: `h` rounded and kept within `[PANEL_MIN, max]`.
  - `keyHeight(key: string, shown: number, max: number): number | null`:
    - `ArrowUp` gives `shown + PANEL_STEP`, and `ArrowDown` gives `shown - PANEL_STEP`.
    - `Home` gives `PANEL_MIN`, and `End` gives `max`.
    - The result is clamped. Any other key gives `null`.
  - `loadPanelHeight(storage?: Pick<Storage, "getItem">): number`:
    - Defaults to `globalThis.localStorage`; reaching it happens inside the `try`.
    - Gives `PANEL_DEFAULT` when the value is missing, non-numeric or non-finite, below `PANEL_MIN`, or the read throws.
  - `savePanelHeight(h: number, storage?: Pick<Storage, "setItem">): void`: writes `String(Math.round(h))`, and swallows any throw.

### Task 2: Resizable bottom panel (F37)

**Files:**
- Create: `src/renderer/Splitter.tsx`
- Modify:
  - `src/renderer/BottomPanel.tsx`: the `section` drops `h-48 shrink-0`, gets `min-h-24` (96 px), an inline `height` from the prop, and `data-testid="bottom-panel"`. The `Splitter` renders as its first child.
  - `src/renderer/App.tsx`: root gets `overflow-hidden` and `data-testid="app"`. `main` swaps `min-h-0` for `min-h-30` (120 px) and gets a ref. The height signal lives here.

  - `e2e/panel.spec.ts`: replace the spike test.

**Interfaces:**
- Consumes: Task 1's exports.
- Produces:
  - `App` holds `const [height, setHeight] = createSignal(loadPanelHeight())`, read once at creation so the first paint uses it, and `const [dragging, setDragging] = createSignal(false)`.
  - The root's class adds `cursor-row-resize select-none` while `dragging()`. Task 3 adds the busy class next to it.
  - `BottomPanel` gains props `height: number`, `setHeight: (h: number) => void`, `main: () => HTMLElement | undefined` and `setDragging: (on: boolean) => void`, and passes them to `Splitter` with its own `section` element.
  - `Splitter(props: { panel: () => HTMLElement | undefined; main: () => HTMLElement | undefined; setHeight: (h: number) => void; setDragging: (on: boolean) => void })` renders:
    - a `div`, `h-1.5` (6 px), `shrink-0`, `cursor-row-resize`, with the tab bar's background (`bg-zinc-50 dark:bg-zinc-800`) and a visible focus ring;
    - `tabindex="0"`, `role="separator"`, `aria-orientation="horizontal"`, `aria-label="Resize bottom panel"`;
    - `aria-valuemin={PANEL_MIN}`, `aria-valuemax={max()}` and `aria-valuenow={shown()}`.
  - It measures with a `ResizeObserver` on the panel and on `main`:
    - `shown` is the panel's rounded height;
    - `max` is `maxPanel(main height + panel height)`.

  It sets the observer up in `onSettled` and disconnects it on cleanup.
  - Its pointer and key handling:
    - **Pointer down:** capture the pointer, and remember the start Y and the start shown height.
    - **Pointer move:** call `setHeight(clampPanel(start + startY - y, max))`.
    - **Pointer up, `pointercancel` or `lostpointercapture`:** save the last height with `savePanelHeight`, then `setDragging(false)`. The drag must end exactly once.
    - **Key down:** `keyHeight` with the key; when it is not null, `preventDefault`, `setHeight` and `savePanelHeight`. Tab is never prevented.

```css

  button:enabled,

  textarea {

  input:disabled,
  label:has(input[type="checkbox"]:disabled) {
    cursor: not-allowed;
```
