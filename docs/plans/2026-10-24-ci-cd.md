# CI/CD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GitHub Actions checks, Windows tests, tag releases and Dependabot for karate-kid, within the free private plan.

**Architecture:** Three workflows: `checks.yml` (Linux, every PR), `test.yml` (Windows, code PRs, e2e only when not a draft), `release.yml` (Windows, `v*.*.*` tags). Commit and branch rules live in a tested Node script, `scripts/check-pr.mjs`. Dependabot config plus two repo settings cover dependency updates and alerts.

**Tech Stack:** GitHub Actions, Dependabot, Node 24, npm, Vitest 5.0.5, Electron Forge 8.0.1.

**Spec:** [ADR 0007](../decisions/0007-github-actions-ci-cd-on-the-free-private-plan.md)

## Global Constraints

- Actions pinned by full SHA with a version comment: `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1`, `actions/setup-node@949feb2413d6458794dcd2491c4babbbce0c15c1 # v7.1.0`, `actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9 # v6.1.0`.
- `node-version: 24`. Every workflow: top-level `permissions: contents: read`; only `release.yml` raises it to `contents: write`.
- Windows workflows set `defaults.run.shell: bash` (the default `pwsh` does not expand globs or `$VAR`).
- npm packages pinned to exact versions (no `^`, `~`).
- Never run `npm test` and `npm run e2e` at the same time (AGENTS.md); in CI they run as steps of one job.
- No Actions artifacts uploaded (500 MB quota).
- Commits follow Conventional Commits (ADR 0003); one logical change per commit.

## Review Focus

1. A draft PR marked ready for review with no new commit must run e2e: `test.yml` lists `ready_for_review` in its PR types (Task 5 verification).
2. A docs-only PR must run `checks.yml` and skip `test.yml` (Task 5 verification).
3. A `develop` → feature merge commit inside a PR must not fail the commit check; `git log --no-merges` skips it (Task 2 test: CLI over a real range).
4. Dependabot PR titles break the 72-character rule; the commit check skips heads starting with `dependabot/` (Task 2 test).
5. A tag that does not match `package.json` must fail before `make` (Task 4 verification).

### Task 2: Commit and branch check script

**Files:**
- Create: `scripts/check-pr.mjs`, `scripts/check-pr.test.ts`

**Interfaces:**
- Produces: `commitError(header: string): string | null`, `branchError(head: string, base: string): string | null` (null = valid, else a one-line reason). CLI `node scripts/check-pr.mjs` reads env `HEAD_REF`, `BASE_REF`, `BASE_SHA`, `HEAD_SHA`, prints one `::error::<reason>` line per problem, exits 1 on any.

- [ ] **Step 1: Write the failing tests** in `scripts/check-pr.test.ts` (same style as `fetch-vendor.test.ts`):
  - `commitError` returns null for `docs(agents): add subagent model selection rule (#5)`, `feat(runner)!: drop java 17`, `ci: add checks workflow`.
  - Non-null for: `Add thing` (no type), `feature: x` (unknown type), `fix(Runner): x` (scope not `[a-z0-9-]`), `fix: Add x` (upper-case subject), `fix: add x.` (trailing period), `fix:add x` (no space), a 73-character header.
  - `branchError` null for `feature/ci-cd`→`develop`, `dependabot/npm_and_yarn/x`→`develop`, `release/1.0.0`→`main`, `release/1.0.0`→`develop`, `hotfix/1.0.1`→`main`, `hotfix/1.0.1`→`develop`.
  - Non-null for `feature/x`→`main`, `develop`→`main`, `fix-thing`→`develop`.
- [ ] **Step 2:** `npx vitest run scripts/check-pr.test.ts` → FAIL (module missing)
- [ ] **Step 3: Implement** `scripts/check-pr.mjs`. Header regex: `^(feat|fix|docs|refactor|perf|test|build|ci|chore|revert)(\([a-z0-9-]+\))?!?: \S`; then subject must not start `[A-Z]`, not end with `.`, header ≤ 72. CLI: branch check always; commit check skipped when `HEAD_REF` starts with `dependabot/`; subjects from `git log --no-merges --format=%s BASE_SHA..HEAD_SHA` via `execFileSync` (no shell). Run the CLI only when invoked directly (same guard as `fetch-vendor.mjs`).
- [ ] **Step 4:** `npx vitest run scripts/check-pr.test.ts` → PASS
- [ ] **Step 5:** CLI over a real range with a merge commit: `HEAD_REF=feature/ci-cd BASE_REF=develop BASE_SHA=dc5de83 HEAD_SHA=0fd744c node scripts/check-pr.mjs` → exit 0 (range holds `Merge pull request #3/#4`, skipped). Same range with `BASE_REF=main` → exit 1 with one `::error::` line for the branch.
- [ ] **Step 6:** Commit `ci: add commit and branch check script`
