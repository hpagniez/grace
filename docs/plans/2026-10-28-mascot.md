# Mascot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grace, the mascot, on the home screen when no project is open and at the top of the README.

**Architecture:** One hand-written `assets/mascot.svg`. The home screen imports it with `?no-inline`, so Vite always emits a file: the CSP (`default-src 'self'`) blocks `data:` images. The README links the same file.

**Tech Stack:** SolidJS 2, Vite 8, Vitest 5, Playwright 1.64.

**Spec:** [ADR 0013](../decisions/0013-rename-the-app-to-grace.md), section Icon and mascot.

## Global Constraints

- Branch `feature/mascot`. Conventional Commits, AGENTS.md rules. No new dependency.
- Drawing (ADR 0013): Grace mid-strike, side-on, plain white gi, hair tied back, green belt `#3fcf6e` matching the strike; a large cartoon moth with a strip of tape on one wing. Flat vector, thick outlines, 3 colours plus neutrals, legible on the light and dark themes. Never the crane-kick pose, a rising-sun headband, bonsai, anything like Karate Labs' logo, Japanese text, or a sexualised or stereotyped character. No animation, no change with the run result.
- Legibility on both themes: the figure sits on a pale disc, so its dark outlines read on the dark theme too.
- The image is decorative on the home screen (`alt=""`): the heading already says what the screen is for. The README gives it real alt text.

## Review Focus

1. **CSP**: the built home screen loads the image from a file, not `data:`. Check: Task 2 e2e asserts the image loaded (`naturalWidth > 0`).
2. **Screen readers**: the image is skipped. Test: Task 2 `the mascot is decorative`.
3. **Home screen only**: an open project shows no mascot. Test: Task 2 `an open project hides the mascot`.
