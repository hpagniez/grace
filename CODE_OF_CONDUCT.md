# Code of conduct

Grace follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the issues, pull requests and every other space of this project, and to anyone who represents the project elsewhere.

## Report a problem

Report behaviour that breaks the code of conduct privately, through GitHub's private reporting form: [Report a vulnerability](https://github.com/hpagniez/grace/security/advisories/new). The form is meant for security reports; start the title with `Conduct:`. Only the maintainer sees it.

You can also report a comment or an account to GitHub with **Report content**.

The maintainer reviews every report, keeps the reporter's name private, and acts on it as the Covenant's enforcement guidelines describe: a correction, a warning, a temporary ban or a permanent ban.
